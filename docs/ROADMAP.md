# Roadmap

- Phase 1 follow-up: real Muse acceptance in an installed/authorized environment; verify CLI version and read-only profile enforcement on the target machine. Signed/notarized installers and Windows smoke tests. Add further provider adapters only through documented official interfaces.
- Phase 2: real local persistent shared VM, per-Bot isolated desktop/browser operation sessions, authorized shared filesystem, file/browser leases, live screenshots and human takeover. Add user-approved bounded write tools only after the operation boundary exists.
- Phase 3: persistent cloud VM per workspace, per-session channels, remote viewing, lifecycle/cost controls, explicit file sync and local/cloud migration. No cloud deployment in phase 1.
- Phase 4: safe parallel scheduling, model-planned task graphs and reviews, durable queue/database as needed, long-term memory, skills and scheduled tasks.
- Later: mobile/voice, demonstrated workflow learning, additional official subscription integrations where supported. No dates or unsupported provider claims.
